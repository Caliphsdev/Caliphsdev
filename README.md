## What I do

I started in geology and fieldwork, then taught myself to code so I could build the tools the industry was missing. Today I work as an independent developer, shipping software for mining and environmental clients.

- 🖥️ **Desktop applications** in PySide6, built on strict MVC architecture
- 🌐 **Web apps and APIs** with Django, FastAPI, React and PostgreSQL
- 🤖 **Machine learning** for prediction and classification with scikit-learn and PyTorch
- 🗺️ **Geoscience work**: groundwater modelling, remote sensing and ArcGIS Pro mapping
- 🔬 **Research** on PFAS contamination modelling in Africa

## Featured projects

### 🛰️ [StrataScope](https://github.com/Caliphsdev/stratascope-releases)
A Windows desktop application for geologists. It guides a user from choosing a study area, through satellite imagery (Sentinel-2, Landsat, ASTER) and terrain data (SRTM), to reproducible maps and A4/A3 reports. Published as a free pilot through [MSONICOP](https://github.com/Caliphsdev/stratascope-releases); the application source is proprietary, and this repository holds the installers, release notes and update metadata.
`Python` · `PySide6` · `Remote sensing` · `Windows installer`

### ⚗️ [Digital Reactor](https://github.com/Caliphsdev/digital-reactor)
A desktop research application for tracking PFAS and other emerging contaminants through a lab-scale activated sludge reactor (OECD 303A design). It includes a live animated reactor diagram, experiment and daily-log management, a mass balance calculator, and a two-phase simulation that moves from textbook equations to a data-driven ML model. It also models real wastewater plants as scientific digital twins.
`PySide6` · `SQLAlchemy` · `scikit-learn` · `pytest` · `PyInstaller`

### 📈 [Forex Machine Learning](https://github.com/Caliphsdev/Forex-machine-learning)
A research project that asks one question honestly: can simple models find a tradable edge in retail forex? It covers an LSTM pipeline from MT5 to SQLite to PyTorch, with leak-tested walk-forward validation, real recorded spreads and pass marks written down *before* each experiment. The result is four documented negative findings and a reusable test harness, backed by 191 automated tests.
`Python` · `PyTorch` · `Time series` · `Reproducible research`
